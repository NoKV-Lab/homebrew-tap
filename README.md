# NoKV Homebrew Tap

This is the official public, source-only Homebrew tap for
[NoKV](https://github.com/NoKV-Lab/NoKV).

## Install

```shell
brew install NoKV-Lab/tap/nokv
```

The fully qualified command adds this tap and trusts only the `nokv` Formula.
No GitHub repository credentials are required.

The current source Formula release gate covers Apple Silicon and Intel macOS.
Linuxbrew is not yet a qualified release target.

Verify the installed release and Workbench contract with:

```shell
nokv version --json
nokv schema
```

## Update

```shell
brew update
brew upgrade nokv
```

The Formula version follows the stable NoKV release tag. Each Formula downloads
the matching immutable source archive and carries the exact source checksum,
NoKV commit, `Cargo.lock` checksum, and Holt version/source/checksum. Holt and
Homebrew build-dependency updates reach this tap only through a new NoKV
release.

Formula updates are generated by the NoKV release workflow only after the
source release and Apple Silicon and Intel Homebrew installation gates pass.
